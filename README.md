## ✨ Meet DHWANI

We already know how to talk to technology.

**Dhwani asks a different question:**

### *What if technology could truly listen?*

Dhwani is a **modern, voice-first AI interface** designed to make interacting with intelligent systems feel as natural as having a conversation.

Speak your question.
Dhwani understands it.
Relevant knowledge is retrieved.
And an intelligent, grounded answer comes back to you.

Powered by its own Retrieval-Augmented Generation pipeline, Dhwani turns speech into grounded, intelligent answers — wrapped in a futuristic, sci-fi-inspired interface.

> 🎙️ **Your Voice. Intelligent Answers.**

---

## 🚀 How It Works

Dhwani connects a futuristic voice interface to an AI and RAG pipeline.

```text
🎤 VOICE
   ↓
🗣️ SPEECH-TO-TEXT
   ↓
🧠 MULTILINGUAL EMBEDDINGS
   ↓
🔎 VECTOR RETRIEVAL
   ↓
📚 RELEVANT CONTEXT
   ↓
✨ AI GENERATION
   ↓
💬 GROUNDED ANSWER
```

### The experience

**🎙️ Voice**

Ask your question naturally.

**🗣️ Understand**

Your speech is converted into text and processed by the AI pipeline.

**🔎 Retrieve**

Relevant information is retrieved from the knowledge base.

**🧠 Reason**

The AI uses the retrieved context to generate a grounded response.

**🔊 Answer**

The system delivers an intelligent response back to you.

## 🧠 Intelligence Behind DHWANI

| Layer              | Technology                     |
| ------------------ | ------------------------------ |
| ⚡ Backend          | FastAPI                        |
| 🎤 Speech-to-Text  | Sarvam AI                      |
| 🧠 Embeddings      | BAAI BGE-M3                    |
| ⚙️ Local Inference | OpenVINO                       |
| 🔎 Vector Database | Qdrant                         |
| ✨ LLM              | Gemini                         |
| 🔗 Architecture    | Retrieval-Augmented Generation |

This architecture allows Dhwani to combine **voice interaction, multilingual understanding, semantic retrieval, and grounded AI generation** — all in a single, self-contained pipeline.

Dhwani currently supports:

## ⚡ Getting Started

### 1. Clone the repository

```bash
git clone <repository-url>
cd dhwani
```

### 2. Install dependencies

If your frontend uses a package manager:

```bash
npm install
```

### 3. Configure the backend

Make sure the backend is running and the frontend is configured with the appropriate backend/API URL.

### 4. Start the frontend

```bash
npm run dev
```

Then open the local development URL shown in your terminal.
